How to use this Seasonal Habit Tracker

The Seasonal Habit Tracker runs for 3 months (13 weeks). When the season changes, you review and change your goals and desired habits to match the new season.

As the days, weeks and months progress you tick off your Habits for that period. Your Habits should be positive – things you aim to do every day, or week or month. The Habit Tracker includes a scoring system that monitors your progress in achieving your Habit aims.

SETTING UP

Set the Season

  • Change the name of the Season beside the heading at top of the page. This will be the name of the saved csv file. (click on season name to edit it).
  • Set the date (a Monday) when you want the season to start. (click on edit start date).

Thresholds and Colours

  • Scores are measured in percentages. Scores show the percentage of habits you ticked off in a given time period – e.g. day, week, month or overall (overall is the full 13 week season)
  • Colours change to indicate better performance.
  • You can set the Thresholds and Colours. Click the box at top right of the Tracker to change the Thresholds and Colours.

Weekly Choice Row

  • Near the top of the page is a row of horizontal icons showing weeks numbered W1 to W13. You use this to select the week you want to show (click on the week number you want).

Goals & Habits for this Season

  • Set 3 Goals for this season. You are limited to 3 goals to help focus your efforts for this time period.
  • In the next section you list your recurring Daily Habits to achieve each goal. When the Daily Habits are filled in you can flip the side arrow beside each Goal to show the Daily Habits relating to each Goal.
  • The Panel to the right of this has Scores showing performance in doing Daily Habits.

Daily Habits

  • Edit and add your Daily Habits in this table
  • Use the + button to add a new Daily Habit
  • Assign each Habit to one of the Goals you are trying to achieve
  • Move the Habits up or down with arrows on right hand side

Weekly Habits

  • Edit and add your Weekly Habits in this table
  • Use the + button to add a new Weekly Habit
  • Move the Habits up or down with arrows on right hand side

Monthly Habits

  • Edit and add your Monthly Habits in this table
  • Use the + button to add a new Monthly Habit
  • Move the Habits up or down with arrows on right hand side

Edits during the season

  • The Habit Tracker only has one setup state. You can edit Goals and Habits during the Season but these also make the same changes to periods already completed.

USING THE TRACKER

  • Use Weekly Choice row to select the week you want to show (from W1 to W13)
  • Daily – tick off the Daily Habits you achieved each day
  • Weekly – tick off the Weekly Habits you achieved each week.
  • Monthly – tick off the Monthly Habits you achieved in each 4 or 5 week period.
  • Review. At the end of each week note down what went well and what you hope to improve in the following week.
  • Click the notepad icon on the date line any time to reopen these instructions.

OTHER BUTTONS

  • Google Drive - Connects browser page to Google Drive to save and sync your data automatically across devices.
  • Save All to Drive – Saves current data to Google Drive in JSON file.
  • Disconnect – Disconnects browser page from Google Drive
  • Export data as CSV - downloads your data to a CSV file. When you start a new season existing data in the browser is lost. If you want to preserve the data for a period you need to save it separately.
  • Start New Season - Starts a new Season and archives the current season
  • Clear this week – Clears only the current week's ticked Habits. It does not clear Monthly Habits – if you want to clear those you have to manually untick them.
  • Reset all data – This wipes all data in the Tracker. Be cautious about this, the data is not recoverable. There is a confirmation warning when you click the button.
